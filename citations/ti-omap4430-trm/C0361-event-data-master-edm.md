TI's OMAP4430 TRM (swpu231ap) uses `general-purpose data master` on page 2988. It backs the glossary
unit `Event Data Master (EDM)`: responds to events (end of an ISP pass, end of a tile, end of a
render, a parameter stream breakpoint) with a host interrupt or a PDS program.
