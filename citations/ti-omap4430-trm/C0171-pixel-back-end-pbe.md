TI's OMAP4430 TRM (swpu231ap) uses `pixel coprocessor` on page 2988. It backs the glossary unit
`Pixel Back End (PBE)`: the last pixel stage: formats the pixel data written to memory, gives the
USSE the output buffer's address, dithers and packs.
