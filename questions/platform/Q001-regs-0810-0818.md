The init script's part 2 opens with three writes: `0x0818 = 0x7ff`, `0x0810 = 0x1`, `0x0814 =
0xffff` (E006). Nothing else in the boot payload or the DDK names them, the microkernel does not
reach them (E010), and the public Rogue and Apple AGX sources have no register that fits.

The values read as a one-bit enable left on (`0x0810`) and two masks or limits left at their
widest, 16 bits (`0x0814`) and 11 bits (`0x0818`) [infer]. A probe that reads back which bits
each register implements, and then reruns a fill, a copy and a triangle with each register
narrowed (0, single bits, the written value with bits cleared), would show whether any of them
changes timing or output; a load that reaches the limits they would set would test the mask
reading.
